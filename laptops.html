Dicas antes de comprar

  • 16 GB RAM é o ideal — Claude + Slack + VS Code + browser abrem pesado
  • Prefira USB-C com carregamento (mais fácil em viagem, um cabo a menos)
  • Verifique se a RAM é soldada ou tem slot livre pra upgrade futuro
  • Fora das promoções (Black Friday, Amazon Prime Day) os preços sobem 15–20%
  • Para Claude Code, o único requisito real é conexão estável — não precisa de GPU
  • Compre com nota fiscal — essencial pra garantia e reembolso de ICMS em alguns estados
  • Peso abaixo de 1,5 kg faz diferença real depois de 4h andando com a mochila
